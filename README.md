# Future Interns - Task 1: Sales Analytics

## Project Overview
This project analyzes sales data using Python, Pandas, and Matplotlib.

## Dataset
Sample Superstore dataset.

## Analysis Performed
- Total Sales
- Total Profit
- Total Quantity
- Sales and Profit by Category
- Sales and Profit by Region
- Monthly Sales Trend
- Average Profit by Discount Level
- Top Products
- Customer Segment Analysis

## Key Findings
- Best Category: Technology
- Best Region: West
- Best Customer Segment: Consumer
- Top Product: Canon imageCLASS 2200 Advanced Copier

## Tools Used
- Python
- Pandas
- Matplotlib
- Google Colab
- Jupyter Notebook

## Conclusion
The analysis shows that Technology is the strongest category and the West region generates the highest sales. The Consumer segment is the largest customer segment. The analysis also shows that excessive discounts can negatively affect profitability.
